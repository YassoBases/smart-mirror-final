# Archived: BLIP-2 captioning approach

An earlier version of the wardrobe classifier fine-tuned BLIP-2 with LoRA to emit
attribute JSON. It was replaced by the CLIP frozen-backbone approach in the parent
directory, which trains far fewer parameters and runs within a much smaller VRAM
budget.

These files are kept as a record of the explored alternative. They are not part of
the delivered system and are not expected to run.
